One line, at most 200 characters, on the dumbest thing my agent did today: it read a 74-kilobyte rulebook cover to cover just to write a single sentence, then saved it in the wrong folder. The program writes that line deterministically to `entry.txt` — the same bytes on every run, no network.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/dumbest-out node main.ts
```
